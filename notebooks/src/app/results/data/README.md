# Data

This folder documents the datasets used in the Gold Trend Forecasting project.

The project uses historical XAU/USD market data together with selected technical and macroeconomic indicators.

Raw datasets are not automatically included in this repository because some data sources may have redistribution or licensing restrictions.

Processed datasets used for model development may be added here where redistribution is permitted.

## Data Categories

- XAU/USD historical market data
- Technical indicators
- Macroeconomic variables
- Processed model-ready datasets

## Notes

Users who wish to reproduce the project should obtain the required market and macroeconomic data from the original data providers and follow the preprocessing steps described in the project notebooks.
